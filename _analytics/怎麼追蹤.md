## 用兩套，定位不同

| 工具 | 角色 | 能不能看「每天每頁瀏覽量」 | 自動存檔 |
|---|---|---|---|
| Vercel Web Analytics | 內建、隨手看「有沒有人來」。免費版只看近 30 天、無公開 API | 可看每頁，但只有 30 天視窗 | 不適合（無穩定 API） |
| GA4（Google Analytics） | 長期報表、可程式化、可自動匯出 | 可，每天每頁都查得到，且永久 | 可，GA4 Data API + Apps Script 每 10 天寫進 Google 試算表 |

「每天每頁瀏覽量 + 自動統計 + 自動存檔」這三個需求，靠的是 **GA4**。Vercel Analytics 是輔助的快速儀表板。

## 還差這幾步（需要江江本人操作，AI 不能代做帳號類動作）

### A. 啟用 Vercel Analytics（1 分鐘）
1. Vercel 後台 → 專案 ai-km-jiang → **Analytics 分頁 → Enable**（選免費 Hobby）。
2. 啟用後要**重新部署一次**才生效（舊部署沒有 analytics 路由會 404）。部署一律從 repo 根目錄 `vercel --prod`。
3. 驗證：`curl -s -o /dev/null -w "%{http_code}" https://jiangyude.com/_vercel/insights/script.js` 回 200 = 生效。

### B. 建 GA4 資源、拿 Measurement ID（5 分鐘，要 Google 帳號）
1. analytics.google.com → 管理 → 建立 → 資源。
2. 資源名稱「江江官網 ai-km-jiang」、時區台灣、貨幣新台幣。
3. 業務目標勾「瞭解網站流量」→ 資料收集選「網站」→ 填 `https://jiangyude.com` + 加強型評估開啟。
4. 在「網頁串流詳情」記下兩個 ID：
   - **Measurement ID `G-XXXXXXX`**（網頁 gtag 用）
   - **資源的純數字 ID**（如 539651368，自動匯出 Apps Script 用，在「資源設定」找）
5. 把 `G-XXXXXXX` 給 AI（或自己做）：打開 `_analytics/inject-tracking.py`，把 `GA4_ID = ""` 改成你的 ID，跑 `python3 _analytics/inject-tracking.py`，gtag 會注入全站。再 `vercel --prod` 部署。約 24-48 小時後 GA4 開始顯示資料。

### C. 開「每 10 天自動匯出試算表」（要 Google 帳號授權，10 分鐘）
1. 開 `sheets.new`，命名「江江官網流量」。
2. 擴充功能 → Apps Script，貼上 `_analytics/ga4-export.gs`。
3. 把檔案開頭的 `PROPERTY_ID` 改成 B 步驟的**純數字資源 ID**。
4. 左側「服務 +」加 `Google Analytics Data API`（識別碼 AnalyticsData）。
5. 函式選 `setup` → 執行 → **OAuth 授權由江江本人點允許**（會跳「未驗證應用程式」提示，那是你自己 Google 試算表裡的私人腳本，安全，照 SOP 說明放心允許）。
6. 完成後試算表會出現分頁：每日總覽、總覽、熱門頁、來源、國家、裝置、瀏覽器，並排好每 10 天自動跑的觸發器。

## 之後要看流量怎麼辦
- 問「這幾天」→ 看試算表 `每日總覽`（逐日每頁）。
- 問「整體最新」→ 看 `總覽` 最新抓取日。
- 問「哪些頁最多人看」→ 看 `熱門頁`，取最新抓取日那批。
- 這張表也可以丟給 Claude / Codex 讀，自動整理成趨勢回報。

## 注意
- 帳號類動作（OAuth、服務條款、未驗證警告）AI 不代點，江江本人操作。
- 多版本／雙語站關鍵：gtag 一定要靠 `inject-tracking.py` 注入「所有頁含英文頁」，不要逐頁手貼，最容易漏英文那側。
