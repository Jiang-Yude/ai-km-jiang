# 瀏覽計數器 · Upstash + Resend 設定步驟

給 CX（用江江瀏覽器代開）或江江本人照做。**所有金鑰只填進 Vercel 環境變數，絕不貼進對話或筆記。**
碰到登入／2FA／email 驗證／要付錢 → 停下來請江江本人處理，不要自己硬過。

## A. 開 Upstash Redis（免費雲端記事本，存數字）
1. 開 https://upstash.com → 用江江的 GitHub 或 Google 登入。
2. Console → Create Database → 選 **Redis**。
3. 名稱 `ai-km-jiang-views`；Region 選離台灣近的（`ap-northeast-1` 東京 或 新加坡）；方案選 **Free**；Create。
4. 進該資料庫頁面，找 **REST API** 區塊，複製兩個值：
   - `UPSTASH_REDIS_REST_URL`
   - `UPSTASH_REDIS_REST_TOKEN`

## B. 開 Resend（免費寄信，給每週報告）
1. 開 https://resend.com → 註冊/登入（江江帳號）。
2. API Keys → Create API Key（名稱 `ai-km-jiang`，權限 Send）→ 複製 `re_...` 開頭的 key。
3. 寄件人先用預設 `onboarding@resend.dev` 即可（之後要用自己網域再驗證）。

## C. 把金鑰填進 Vercel（專案 ai-km-jiang）
1. 開 https://vercel.com → 專案 **ai-km-jiang** → Settings → Environment Variables。
2. 新增以下（Environment 勾 Production，也可全勾）：
   | Key | Value |
   |---|---|
   | `UPSTASH_REDIS_REST_URL` | （A 的 URL） |
   | `UPSTASH_REDIS_REST_TOKEN` | （A 的 token） |
   | `RESEND_API_KEY` | （B 的 re_... key） |
   | `REPORT_EMAIL` | `thedav1035@gmail.com` |
   | `CRON_SECRET` | 隨機一串長字（防止每週信端點被外部亂打） |
3. Save。

## D. 完成後
- 回報「金鑰已填好」（不用貼金鑰內容）。
- 由 Claude 這邊做：把計數 snippet 注入各頁 → 部署 → 測試 `/stats` 有數字、`/api/view` 回 200。
- 每週一早上 9 點（台灣）會自動寄流量信到 REPORT_EMAIL（也是 Upstash 的每週備份）。

## 驗收（部署後）
- `curl -s -X POST https://ai-km-jiang.vercel.app/api/view -H 'content-type: application/json' -d '{"path":"/","increment":false}'` → 回 JSON 有 page/global。
- 開 https://ai-km-jiang.vercel.app/stats → 看到全站總數與當月每日長條。
