# 瀏覽計數器 · 設定步驟（純 Vercel 後台版，最簡）

只要在 Vercel 後台建一個內建 Redis（Vercel 的「筆記本」），計數器就會動。不用去別的網站、不用複製金鑰。無 email、無 cron。

## 唯一要做的：在 Vercel 建一個 Redis
1. 開 https://vercel.com → 專案 **ai-km-jiang**。
2. 上方分頁 **Storage** → **Create Database**。
3. 選 **Upstash for Redis**（清單裡的 Redis）→ 名字 `views` → Region 東京/新加坡 → Create。
4. 按 **Connect Project** → 選 `ai-km-jiang` → Connect。
   - Vercel 會自動把 `KV_REST_API_URL`、`KV_REST_API_TOKEN` 加進專案，你不用複製任何金鑰。
5. 回報「Redis 連好了」。Claude 這邊會：注入計數 snippet → 部署 → 測 `/stats`。

## 之後怎麼用
- **網頁上**：各頁顯示自己的瀏覽數；首頁顯示首頁數＋全站總數；深度文章列表顯示文章區小計；`/stats` 頁有當月每日長條＋歷月清單。
- **每月自己讀（CC／CX 分析）**：`/api/stats` 是公開 JSON，直接讀就有全部數字：
  ```
  curl -s https://ai-km-jiang.vercel.app/api/stats
  ```
  回傳 { today, days:[{date,count}], months:[{month,count}], total }。丟給 Claude/Codex 就能整理成報表。

## 驗收（部署後）
- 開 https://ai-km-jiang.vercel.app/stats → 看到全站總數與當月每日長條。
- `curl -s -X POST https://ai-km-jiang.vercel.app/api/view -H 'content-type: application/json' -d '{"path":"/","increment":false}'` → 回 JSON 有 page/global。

## 給接手 AI 的備註
程式相容兩種金鑰命名：Vercel Storage 的 `KV_REST_API_URL/TOKEN` 與 Upstash 的 `UPSTASH_REDIS_REST_URL/TOKEN`（見 api/view.js、api/stats.js）。任一組存在即運作。已移除 Resend 每週信與 cron（江江改為每月自讀 /api/stats）。
