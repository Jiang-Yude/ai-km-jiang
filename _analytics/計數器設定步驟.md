# 瀏覽計數器 · 設定步驟（純 Vercel 後台版，最簡）

不用跑去 Upstash/Resend 各自註冊、不用手動複製金鑰。全部在 Vercel 後台點完，Vercel 會自動把金鑰塞進專案。

## 第一步（計數器就會動）：在 Vercel 建一個 Redis
1. 開 https://vercel.com → 專案 **ai-km-jiang**。
2. 上方分頁點 **Storage** → **Create Database**。
3. 選 **Upstash for Redis**（或清單裡的 Redis）→ 名稱隨意（如 `views`）→ Region 選東京/新加坡 → Create。
4. 建好後點 **Connect Project** → 選 `ai-km-jiang` → Connect。
   - Vercel 會**自動**把 `KV_REST_API_URL`、`KV_REST_API_TOKEN` 加進專案環境變數，你不用複製任何東西。
5. 到 Deployments 點最新一筆 **Redeploy**（或等我這邊 push 觸發）。

做完這步：每頁計數 + `/stats` 統計頁就會開始運作。

## 第二步（選配，之後再做）：每週流量 email 備份
1. Vercel → 專案 → **Integrations**（或 Marketplace）→ 找 **Resend** → Add/Connect → 授權。它會自動加 `RESEND_API_KEY`。
2. 專案 → Settings → Environment Variables，手動再加兩個：
   - `REPORT_EMAIL` = `thedav1035@gmail.com`
   - `CRON_SECRET` = 隨便一長串（防端點被外部亂打）
3. Redeploy。之後每週一早上 9 點（台灣）自動寄流量信，也是 Upstash 資料的每週備份。

## 完成後回報
- 回「Redis 連好了」即可（不用貼任何金鑰）。Claude 會做：注入計數 snippet → 部署 → 測 `/stats`。

## 驗收（部署後）
- 開 https://ai-km-jiang.vercel.app/stats → 看到全站總數與當月每日長條。
- `curl -s -X POST https://ai-km-jiang.vercel.app/api/view -H 'content-type: application/json' -d '{"path":"/","increment":false}'` → 回 JSON 有 page/global。

## 給接手 AI 的備註
程式已相容兩種金鑰命名：`UPSTASH_REDIS_REST_URL/TOKEN` 與 Vercel Storage 的 `KV_REST_API_URL/TOKEN`（見 api/view.js、api/stats.js、api/weekly-email.js）。任一組存在就會運作。
