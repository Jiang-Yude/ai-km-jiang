這兩個月我都用 Claude Code 在剪片：從企劃書轉成提案說明片，從官網轉成介紹影片。Claude Code 是 Claude 的一種用法，要付費訂閱 Claude 才能用，它可以直接在你的電腦上寫程式、跑程式，影片就是它寫程式一格一格做出來的。

做下來我覺得要處理好四件事：配樂從哪來、旁白怎麼配、畫面怎麼卡在拍子上、內容的架構。這篇一件一件講。

先看成品：39 秒的一個月陪跑介紹片

這支片的內容是從我的官網轉過來的。配樂是我讓 Claude 用免費的樂器音色庫編出來的；旁白是 Claude 寫稿，再交給 Google 的語音合成念的；畫面出現的時間，也是照這首配樂的拍點排的。

影片在 YouTube：江江教練一個月陪跑介紹。下面是幾個畫面。

下面四段，就是這支片背後的四件事。

一、配樂從哪來：下載樂器音色庫，或直接用 Suno

叫 Claude 自己做配樂，它是寫程式把聲音合成出來。沒有給它樂器的聲音，做出來的就是很單調的電子合成音樂，很難聽。我一開始的預設配樂就是這樣。

有兩種做法。想最快做出第一支片，先看第二種用 Suno；想自己控制編曲、不受下載額度與商用授權限制，再看第一種。

第一種：下載樂器音色庫，讓 Claude 用真樂器的聲音編曲

音色庫就是一包錄好的樂器聲音，鋼琴、吉他、鼓都有。我用的是免費的 GeneralUser GS，裡面有 259 種樂器、檔案 32MB，授權寫明私人和商用都可以（作者也聲明部分取樣的來源無法百分之百確認，要用在客戶案子之前，可以先看一下授權全文）。Claude 編好曲子，再用這些樂器彈出來，聽起來就差很多。

這個要花一點時間教。我第一次讓它做了五種風格，我聽完都覺得不好聽。後來我丟了一首我喜歡的配樂給它當參考，它才做出我可以用的版本；我又嫌節奏太慢，請它照另一首快歌的節奏手法再做一款，之後鼓聲我又嫌太吵、叫它調小了三次。

現在我把這套做法存成一個自己用的配樂產生器，我叫它配樂機，要配樂就叫它出一首。你也可以請 Claude 照同樣的路走：下載音色庫、給它一首你喜歡的參考曲、聽完告訴它哪裡要改。

第二種：更簡單，直接用 Suno AI 生成配樂

Suno 是做歌的 AI，打幾句描述就能生出一首，可以先用它。下載有限制（2026 年 11 月查 Suno 官方說明）：

  • 免費版每天有 50 點可以生成歌，但下載是一次性的試用額度：2026 年 9 月 3 日以前註冊的帳號最多 7 首，用完不會重置；之後才註冊的帳號不一定有試用下載。
  • 免費版下載的歌只能個人使用，不能商用。
  • 付費的 Pro 方案年繳每月 8 美元，每月可以下載 20 首，有商用權。

所以我的建議是：先生成幾首比較通用的配樂，例如輕快的，以後做片就輪流用。我常用的朵拉（我的 AI 員工）配樂〈Bright Idea Girl〉就是 Suno 做的。

另一支 AI 做的影片，配樂也出過狀況，我另外寫過
  • 我怎麼叫 AI 幫我做摘要影片？｜兩小時辯論變三分鐘懶人包，我下的提示詞與三個坑　這一段只講配樂從哪來，那篇記的是摘要影片的三個坑：逐字稿漏話、數字張冠李戴、配樂忽大忽小

二、旁白怎麼配：Claude 寫稿，Gemini 語音合成一句一句錄，一分鐘不到台幣 1 元

介紹片裡的旁白也是讓 Claude 做的。我先講文案的主軸，Claude 整理成九句旁白稿，再交給 Google 的語音合成 Gemini 3.8 Flash TTS 念出來。

  • 先準備：到 Google AI Studio 申請一組 API 金鑰，讓 Claude Code 用它去呼叫語音合成。
  • 聲音：用同一組 API 金鑰，先用文字描述設計好一個聲音存起來，我用的是幫 AI 員工萊卡設計的聲音。每次錄的時候再加一句語氣說明，這支片寫的是台灣華語發音、沉穩、專業秘書的語氣、講快一點。
  • 一句一個檔：九句分開錄，每句存成一個檔，之後比較好把每句放在對的拍子上，哪句念不好也只要重錄那一句。

費用我照 Google 官方定價算了一下（2026 年 11 月查）：

項目數字
定價每 100 萬個聲音 token 9 美元（2026 年底前；2027 年 1 月 1 日起 18 美元）
一秒的聲音官方寫約 25 個 token
一分鐘旁白約 1,500 個 token，大約 0.014 美元，不到台幣 1 元

有開發者在 Google 論壇回報實測一秒約 32 個 token，照這個算一分鐘約 0.017 美元；2027 年定價加倍後也大約 0.03 美元。就算一句重錄好幾次，一支一分鐘的片，旁白費用都還是以台幣幾元計。

定價來源：Gemini Developer API pricing、Gemini 3.8 Flash TTS。實際扣款以你的帳單為準。

三、畫面怎麼卡在拍子上：先給 Claude 一張卡點表

卡點（也有人叫踩點）的意思是畫面換鏡頭、文字出現的時間，剛好落在音樂的拍子上。

這個做法是亞里教的。亞里是 YouTube「亚里-科技 AI 分享」頻道的創作者，他有一支教學影片〈AI 寫程式做音樂 MV 教程〉，也寫了圖文版；裡面用的工具 mv-director 也是他做的，程式碼公開在 GitHub 上，誰都可以下載。我照著實測，效果不錯喔。

Claude 聽不到聲音，所以要先把音樂整理成卡點表

Claude 聽不到聲音。只丟一首歌給它，它不知道拍子落在哪裡。所以要先用程式把音樂拆成數字，整理成一張表給它，亞里把這張表叫卡點表。

我的配樂機輸出的卡點表有五樣：

卡點表裡的東西它記的是什麼
速度這首歌每分鐘幾拍
小節頭每個小節的第一拍
每一拍每一拍落在哪裡
段落歌分成哪幾段，各從哪裡開始
大時刻整段裡要放大動作的那幾個點

把第五版介紹片配樂的卡點表畫出來，大概長這樣：

亞里的版本另外還有「每個字在第幾秒唱」，用來做「唱到哪個字，畫面就演那個字」。

有了這張表，Claude 就能把換鏡頭、文字出現的時間排在拍子上。

卡點表從哪來，看配樂是自己編的還是現成的歌

配樂是用程式編的

拍點本來就在程式裡，直接輸出卡點表。我的配樂機現在做配樂時會多輸出一份卡點表，表上的拍點和實際聲音差大約 10 毫秒。上面那支介紹片就是走這條路。

現成的歌（例如 Suno 做的）

要先分軌，就是把一首歌拆成鼓、貝斯、人聲幾條聲音，再只從鼓那一條測拍子。亞里提醒整首直接測會測錯，他自己第一次測成每分鐘 99 拍，實際是 149 拍，因為人聲和貝斯也會被當成拍點。mv-director 這些都會幫你做。

我用〈Bright Idea Girl〉第 48 到 86 秒做了一支 37 秒的測試片：13 個鏡頭，換鏡頭 100% 落在拍上，小節頭 15 個全中，第一次草稿就過。

這些數字是做完後用程式從成片檢查量出來的，只代表這一段。

動感型和沉穩型，卡點的強度可以自己調

亞里教學裡的卡點，動態效果很強烈，鼓一下畫面就跟著動，適合音樂 MV。

  • 教學影片〈AI 寫程式做音樂 MV 教程〉：https://www.youtube.com/watch?v=jrkfL0V9-oM

我的介紹片是比較專業的自我介紹，就沒有用那麼強烈的鼓點，因為我覺得會太躁動。我只讓文字、標題、示意圖出現的那一下卡在拍子上，其他時間畫面是穩的。這就是比較沉穩型的解說卡點影片。

要哪一種，可以自己跟 Claude 說，自己調整。

實測卡點的兩個雷：閃白轉場會提早、畫面一直動看不出拍點

  • 閃白轉場會比拍子早大約 0.07 秒（我這次量到的），要卡準就用直接切。
  • 畫面一直動，拍點反而看不出來。測試片我的做法是一拍走一格，拍子到了畫面才動。

想用現成配樂做卡點，可以直接貼給 Claude Code 的三句話

亞里在圖文版裡給了可以直接貼給 Claude Code 的話，我照他的原意轉成繁體：

用途貼給 Claude Code 的話補充
安裝「幫我把 https://github.com/Yari-tuber/mv-director 裝成 skill」裝好要新開一個對話
查環境「檢查一下 mv-director 的環境」
開始做「用 mv-director 給 song.mp3 做一支 MV，做 30 秒左右，你挑最有戲的一段。」他的完整版還會交代歌名、歌詞檔和畫風從哪裡挑

這三句是先讓你跑通「把現成的歌算出卡點、做出卡點畫面」這一段。要做介紹片的話，跑通之後再跟它說畫面要放你的文字和示意圖，卡點要沉穩型。

四、重點還是架構：已經有架構的東西，轉影片最簡單

我之前做企劃書轉影片，現在做官網轉影片，概念都一樣：要講什麼、先講什麼後講什麼先定好，AI 只負責把它轉成畫面和聲音。

所以如果你手上已經有架構好的東西，例如企劃書、報告、文件、網站，轉影片就會更簡單。架構清楚，後面要改的都只是畫面和聲音的細節。

企劃書轉影片的做法，我在這篇脆文分享過，完整版的官網文章還在整理。

哪些是亞里教的、哪些是我加的、哪些我還沒試

亞里教的

先把歌拆成數字再讓 AI 寫畫面、卡點表、先分軌再從鼓軌測拍、做完從成片檢查，還有 mv-director 這套工具。

我自己加的

下載音色庫做配樂機，配樂機直接輸出卡點表；沉穩型的卡點，只在文字、標題、示意圖出現時卡拍。旁白用 Gemini 的語音合成一句一句錄。

我還沒試的

〈Bright Idea Girl〉是純音樂，所以「唱到哪個字，畫面就演那個字」我還沒試。做出來的是一支 MP4，再拿進剪映或 Premiere 修改這件事，我也還沒試。
