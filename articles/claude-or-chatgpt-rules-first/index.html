AI 工具選擇 / 差異比較

ChatGPT 和 Claude 該選哪個？｜ChatGPT 很多能力都有八十分，Claude 把老實可靠聽話做到一百分

完全沒有規矩的話，兩個其實差不多；有規矩的話，Claude Code 會比較遵守規矩。這篇是我陪跑客戶時給的建議：什麼時候用 ChatGPT、什麼時候用 Claude Code。

最近我一直推薦 Claude，而不是 ChatGPT。我的分法其實取決於一件事：你有沒有自己的做事規矩。完全沒有規矩的話，兩個其實差不多；有規矩的話，Claude Code 會比較遵守規矩。這篇是我最近統整陪跑客戶時給的建議：什麼時候用 ChatGPT、什麼時候用 Claude Code、我推薦 Claude 的原因，最後附一張表讓你判斷自己該先用哪個。

適合誰
  • 剛開始用 AI，正在猶豫要訂 ChatGPT 還是 Claude。
  • 已經把 AI 用在工作上，希望交代下去的事不會被亂搞，想找一個比較聽話的 AI 同事。
  • 想知道什麼時候該用 ChatGPT、什麼時候該換 Claude Code。
這篇想說什麼
  • ChatGPT 很多能力，每個都有八十分水準；Claude 是把老實、可靠、聽話做到一百分。
  • 純新手、還沒有規矩，先用 ChatGPT；規矩很多、希望 AI 老老實實做事，Claude Code 是我目前唯一推薦。
  • 我推薦 Claude 的主要原因是安全可靠，外加 Hook 機制；AI 憲法這個概念也很重要。
  • 要畫圖就兩個都訂：ChatGPT 是訂給 Claude Code 畫圖用的。

什麼時候用 ChatGPT，什麼時候用 Claude Code：先看你有沒有自己的規矩

我的原話如果你完全都沒有規矩，那其實兩個都差不多。那你有規矩的話，Claude Code 會比較遵守規矩。我主要核心是這樣子的概念。
純新手、還沒有規矩：先用 ChatGPT
  • 即時語音交互做得很好，跟它聊天很輕鬆，很降低門檻。
  • 要畫畫也不錯。
  • 多功能，很多能力，每個也都有八十分水準。
規矩很多、要認真做事：Claude Code
  • 你希望它是你的 AI 同事。
  • 不會亂搞你，認真聽話。
  • 你交代的事情，就老老實實做完。
  • 它是把老實、可靠、聽話做到一百分。

但我會加一個前提：這是真的要進入工作流程之後再回頭看。你原本就有一些工作流程的概念，工作流程、內容都已經講好，Claude Code 的好處才會出來。所以前期如果你都沒有規矩，請以 ChatGPT 為主。

  • ChatGPT Work、Codex、一般 ChatGPT 怎麼分工？：如果你先從 ChatGPT 家族開始，這篇講它自己的三種工具怎麼分。
  • 想學 Agent，我為什麼會先推薦 Mac？：準備進入 Claude Code 這類 Agent 工具之前，電腦怎麼選。

我推薦 Claude 的主要原因：安全可靠，外加 Hook 機制

我推薦 Claude 的原因主要就兩個：安全可靠，外加 Hook 機制。後面會講的 AI 憲法，是我覺得也很重要的概念。

原因白話
安全可靠交代下去的事老實做完，比較不會為了讓你高興自作主張。
Hook 機制Claude Code 可以設定 Hook：在 AI 動手之前或之後，自動跑一段檢查程式。規則寫成程式直接攔，不靠 AI 自己記得。例如我的知識庫裡，工作日誌一定要上傳，心情日記一定不上傳，這種「一定要」和「一定不」的規矩，就交給 Hook 守。Hook 是 Claude Code 的功能，一般網頁版或 App 的 Claude 沒有。
AI 憲法訓練時就照一部白紙黑字的規矩教，讓 AI 自己對照規矩檢查自己。

規則只寫在文件裡，要靠 AI 讀到、記得；寫成 Hook，每次動手都會被檢查。

延伸閱讀
  • 寫了一堆規則給 AI，為什麼還是沒人執行？：Hook 機械攔截是三種「規則引擎」裡最硬的一種，這篇有我實際怎麼用。
  • AI 規則檔裝了攔截器，52 天一條都沒擋下來：只會提醒的攔截器和真的會擋的攔截器差在哪。

Claude 不畫圖怎麼辦？讓 ChatGPT 當它的畫圖工具

有人會問：我希望 AI 老老實實做事，可是我也要畫圖，Claude 又不畫圖，怎麼辦？

我的做法是 ChatGPT 一起訂，然後請 Claude 去叫 ChatGPT 畫。我會跟 Claude 講我要什麼圖，然後 Claude 叫 ChatGPT 去畫。ChatGPT 畫不好，是 Claude 幫我盯，盯到 ChatGPT 畫好為止。

所以我沒有在管「抽卡」這件事（抽卡＝同一個需求一直重新生圖，碰運氣等一張好的）：

  1. 需求一開始就寫清楚：Claude 一開始就把我要的需求寫得很清楚，ChatGPT 的成功率自然就很高，不用一直抽。
  2. 就算要抽，也是 Claude 去抽：不是叫我抽。

最終是 ChatGPT 生完、Claude 審核都過了、都完整的，才會給我看。我自己都沒在抽過卡。我現在有很多 AI 工具，都是訂給 Claude 用的。

Claude 本身不生成圖片和影片，我是用這種方式補起來。

為什麼 Claude 比較守規矩：兩家訓練 AI 的打分表不一樣

我最近統整了一下陪跑客戶時給的建議。要講清楚為什麼這樣分，先從兩家怎麼訓練 AI 講起。不管哪一家，現在教 AI 大致都是三步：

步驟白話各家差在哪
預訓練把全人類的網頁、書、程式碼讀完，只練「猜下一個字」教材和底層架構，各家已經差不多
監督微調老師拿標準答案示範，教它像正常人一樣回話請什麼樣的老師
強化學習不給範文，自己刷題，老師拿一張打分表，做對給糖、做錯打手板打分表上寫什麼，這一步才是真正分出差別的地方

只做完第一步的 AI 像書呆子，什麼都懂一點，但還不能直接用：你問它「電腦壞了怎麼修」，它可能學著網路論壇的口氣，反問你一句「樓主後來修好了嗎」。所以才需要後面兩步，把它教成能做事的樣子。

差別就在第三步那張打分表。ChatGPT 早期讓它爆紅的做法叫 RLHF：同一個問題讓模型寫兩個答案，請真人考官挑比較喜歡的那個。考官是一般人，一題只給幾分鐘。一個答案乾乾的但是對的，另一個排版漂亮、語氣熱情、開頭先誇你「這個問題問得真好」，考官很容易選第二個。這樣一路打分下來，模型就學會讓你看了舒服。

打分表不同，教出來的學生脾氣就不同：

OpenAI（ChatGPT）Anthropic（Claude）
打分表讓人滿意守住邊界，在真實的工具裡一步一步把活做完
怎麼打分同一題寫兩個答案，讓真人考官挑比較喜歡的（RLHF）照一部寫好的校規，讓 AI 自己對照檢查、自己改（Constitutional AI）
主要練什麼文字、程式、語音、畫圖、影片都練放進真實的大型程式專案，自己翻檔、改程式、跑測試，改到整個專案跑通
像什麼人一個什麼都會、多才多藝，情商比較高的人專業顧問，你要專業建議，它可以給你一針見血的建議；沒人盯著也老實做完
代價容易順著你講；有規矩的時候，不像 Claude Code 那麼會遵守不畫圖，要畫圖得另外訂 ChatGPT；要先把工作流程、內容講好，好處才出來
我的比喻像 GPT，我就覺得它是一個情商比較高的人。Claude 其實就是一個專業顧問，你叫它給專業建議，它也可以給你無情的、一針見血的專業建議。當然，專業顧問也比較貴。

這也是 ChatGPT 的強項。它不只會寫文章、寫程式，即時語音聊天很自然，畫圖也有很強的模型，連做影片都有 Sora。想找一個什麼都會、隨叫隨到的生活與辦公助手，選它沒問題。這就是我說的：很多能力，每個都有八十分水準。

Anthropic 走的是另一條路。Anthropic 的創始團隊是從 OpenAI 出來的，一開始就把 AI 的安全和可控放在前面。Claude 本身不生成圖片和影片，力氣集中在工作場景：讓 Claude 在真實的大型專案裡，自己翻檔、改程式、跑測試，看到滿屏報錯就自己找原因，一直改到整個專案跑通。這也是為什麼我要畫圖時，會另外訂 ChatGPT，給 Claude Code 畫圖用。

公平地說OpenAI 自己也知道討好的問題，一直在修：推理模型會先想清楚再回答，也曾經因為模型太會拍馬屁撤回過一次更新。兩家是起點不同，ChatGPT 本身也持續在調整。

AI 憲法是什麼：讓 AI 照著白紙黑字的規矩檢查自己

AI 憲法，就是 Anthropic 寫給 AI 遵守的憲法，英文叫 Constitutional AI。Anthropic 認為只靠人打分有兩個問題：

  • 考官的水準有高有低，判斷容易被語氣和排版影響。
  • 模型越來越強，一寫就是幾千行程式，裡面有沒有坑，人根本看不過來。

所以他們替 Claude 寫了一部白紙黑字的校規。訓練時讓模型先寫一份回答，再把回答和校規一起交回給 AI 自己看：有沒有不懂裝懂、有沒有安全漏洞，自己改、改完重寫一遍。

除了校規，Anthropic 還會專門練模型的性格（Character Training）。例如你給的指令前後矛盾，Claude 不會硬著頭皮亂猜，會直接跟你說「你這兩句對不上，你到底要哪個」。

我說的一百分，就是這個沒人盯著的時候，也能老老實實把活做完。老實、可靠、聽話，Claude 是做到一百分。

到了 AI 自己拿工具做事的時代，不亂越界、找不到檔案敢直接說「我沒找到」的習慣，比偶爾很聰明更重要。

為什麼「老實」比「聰明」值錢：一件 50 步的工作

算一筆帳就很清楚。現在用 AI 做事，已經從問一句、回十行，變成讓它在背景連續改好幾十個檔案、跑上百步操作。假設一件工作要連續走對 50 步：

每一步照規矩來的機率50 步全部走對的機率
95%約 7.7%（十次有九次多會在半路出包）
99%約 60%

每一步只差 4 個百分點，最後結果差了快 8 倍，工作越長差距越大。出包是什麼樣子？像把不該刪的設定刪掉，或是為了讓測試通過，乾脆把測試本身改掉。

數字怎麼看95% 和 99% 是拿來示範的假設，不是實測。算式可以自己驗：0.95 的 50 次方約 0.077，0.99 的 50 次方約 0.605。

AI 自己做事的時代，比的是能不能連續做八小時不出包

強化學習有一條鐵律：你獎勵什麼，模型就會想盡辦法把那項本事練到極致。

打分表獎勵什麼得到什麼樣的 AI
考官看了舒服能聊能畫、什麼都懂一點的全能選手；但做髒活累活時，偶爾會為了讓你高興自作主張
守住邊界，在真實工具裡一步一步把活做完情緒穩定、特別老實的專業者

這是訓練取向的差別，不是說哪一家一定會出包。等到各家大模型在考卷上的分數都很高、差距很小，接下來比的是什麼？是誰偶爾能冒出一句特別驚艷的話，還是誰能在你睡覺的時候，連續幫你做八個小時的活，一個簍子都不捅？

這就是我說的 AI 同事。我希望它不會亂搞我，認真聽話，交代的事情老老實實做完。前提是規矩要先講好：

我的原話如果你完全都沒有規矩，那其實兩個都差不多。那你有規矩的話，Claude Code 會比較遵守規矩。

Claude 的代價也要先知道

Claude 不是天下無敵，這幾個代價我也照實列出來：

  • 偏科：做海報、配影片、手機上順暢的即時語音聊天，Claude 給不了完整的體驗。
  • 比較貴：專業顧問也比較貴。
  • 有用量上限：訂閱方案有用量上限，程式正寫得起勁，可能突然跳出已達用量上限，只能等。

各家都在互相學，OpenAI 也在努力讓模型更守規矩，今天的領先不保證一直都在。所以我的推薦是「目前」的判斷，工具換版之後要重新看。
