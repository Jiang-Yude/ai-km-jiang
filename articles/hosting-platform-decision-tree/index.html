決策樹 / 網站上線

我做的網頁，要放在哪裡別人才打得開？｜託管平台決策樹，自己用還是做生意、只給人看還是要做事

我有 37 個網站，分別放在三個地方。這篇把我怎麼選整理成一棵樹，你照自己的網頁會做什麼點下去，就知道該放哪。

用 AI 做好一個網頁，接下來要把它放到網路上，別人才打得開。可以放的地方很多：Cloudflare、Vercel、GitHub Pages、Railway、Render，每一家都說很簡單。這篇不比規格，只問你幾件事：自己用還是做生意、只給人看還是要替人做事。照答案走，最後會落在一個地方，每個地方都附上我自己真的放在那裡的網站。

適合誰
  • 用 AI 做好網頁，把網址傳給朋友，朋友說打不開
  • 聽過 Vercel、Cloudflare 這些名字，不知道差在哪
  • 網頁要輸入密碼、要讓人上傳照片，不知道免費的地方放不放得下
  • 要幫客戶做網站，怕選錯地方，之後被收錢或被停用
你可以帶走什麼
  • 一棵點一點就有答案的樹
  • 五種網頁，自己用和做生意各放哪裡，附我自己的例子
  • 一段直接貼給 AI、請它幫你判斷的話

朋友打不開你傳的網址，是因為網頁還在你自己的電腦裡

AI 幫你做好網頁時，打開的網址常常長得像 localhost:3000。localhost 的意思是「這台電腦自己」。朋友在他的手機點這個網址，手機只會找它自己，當然找不到你的網頁。

要讓別人打得開，網頁要放到一台一直開著、有正式網址的電腦上。有三條路：

方法像什麼麻煩在哪
家裡的電腦一直開著在自己家開店停電、斷網、電腦睡著，網站就打不開
租一台空的雲端電腦租一間毛胚屋裝潢、水電、門鎖全部要自己弄
找專門代管網頁的平台進駐百貨公司專櫃要照平台的規矩和免費額度走

第三種平台叫「託管平台」。用 AI 做網頁的人，選這條最省事，這篇講的就是它們怎麼選。

前端和後端：網頁的外場和廚房

選平台之前，要先懂兩個詞。Gary Chen 在影片裡用餐廳來比喻，我覺得最好懂。

前端＝餐廳的外場

客人看得到、摸得到的東西：畫面、文字、圖片、按鈕。訪客打開你的網頁，眼睛看到的全部都是前端。

後端＝餐廳的廚房

客人看不到、但要有人做的事：檢查密碼對不對、把填的資料記下來、收好上傳的照片、拿鑰匙去叫 AI 回答。這些事不能擺在外場給客人看。

很多店只要外場就夠了，像作品集、活動介紹、名片，訪客打開只是看。只有網頁要「替人做事」的時候，才需要廚房。有沒有廚房，會決定你能放在哪裡。

自己用還是做生意，能放的地方不一樣

這是最容易被忽略、也最要先問的一題。三家平台都有免費方案，但「免費能不能拿來做生意」，規定差很多（2026-08-19 我查過三家的條款）：

平台自己用、練習、實驗拿來做生意
GitHub Pages可以，但網站和檔案都是公開的規定不能拿免費的來經營線上生意
Vercel免費版可以免費版只限個人、非商業；做生意要付費版，每月 20 美元起
Cloudflare可以沒有看到「免費版不能商用」的規定，是我做生意網站的免費起點

怎樣算做生意？有收費、接案做給客戶的網站、課程報名頁都算。只是介紹自己付費服務的官網，也算。很多人以為沒有購物車就不算，這是最常選錯的地方。

自己用、實驗性質的東西還有一個要注意：免費額度是整個帳號共用的。實驗做壞了、一直自動跑，會把同一個帳號裡做生意的網站一起拖垮，我遇過（後面「坑」那段會講）。所以實驗和正式網站，最好分開帳號放。

三個問題點下去，看你的網頁該放哪裡

很多人會先去比各家的規格，結果越比越亂。先回答自己的網頁是拿來做什麼的，答案通常只剩一兩家。

Gary Chen 在他的部署教學影片裡，用三個問題幫人選平台。我照自己 37 個網站的經驗改寫成下面這棵樹，加上「做不做生意」和「網址被轉傳沒關係嗎」兩題，因為我的網站有一大半是客戶的、或只給學員看的。這棵樹的題目順序，我和另一個 AI（Codex）各自設計一版再合併。

    決策樹文字版
    1. 第一題：自己用、實驗，還是做生意（收費、接案、客戶網站、介紹付費服務的官網都算）？
    2. 第二題：網頁只是給人看，還是要替人做事（登入、存資料、上傳、問 AI、自動做事）？
    3. 只是給人看 → 網址被轉傳出去，別人看到沒關係嗎？沒關係：公開展示頁（做生意放 Cloudflare Pages；自己用 GitHub Pages、Vercel 也可）；沒關係但不想被搜到：Cloudflare Pages 設定不讓搜尋引擎收錄；不行：要密碼，算替人做事
    4. 替人做事 → 事情怎麼進行？有人按才做、幾秒就好：做生意放 Cloudflare，自己用 Vercel 免費版或 Cloudflare；時間到自己做或接 LINE 訊息：Cloudflare Workers；要一直開著或跑很久：Railway、Render

    只是給人看的網頁：先問網址被轉傳出去，別人看到沒關係嗎

    名片、作品集、活動介紹、課程簡介、簡報，只要外場、不用廚房。這種網頁放哪裡都很便宜，差別在「做不做生意」和「給誰看」。

    轉傳沒關係，希望越多人看到：公開展示頁

    放哪裡我的例子
    做生意Cloudflare Pages，免費攝影公司的網站：161 頁、2.5 GB，從 Webnode 整站搬過來，現在每個月零元
    自己用、實驗GitHub Pages、Cloudflare Pages、Vercel 免費版都可以我的 AI 名片，早期放在 GitHub Pages

    2026 年 8 月起，我新做的網頁都放 Cloudflare，GitHub Pages 上的舊站只維護不新增。

    整站搬家的過程，我另外寫過
    • 官網搬家一個月零元：把攝影網站從 Webnode 整站搬到 Cloudflare Pages　這一段只講它放哪裡，那篇講怎麼搬，以及搬家時差點漏掉六成圖片的坑。

    轉傳沒關係，但不想被 Google 搜到：私下分享頁

    文章草稿、會議整理、給客戶的提案。我放 Cloudflare Pages，網址取一串別人猜不到的名字，再設定「不讓搜尋引擎收錄」，收到網址的人手機一點就能看，不用登入。做生意和自己用都這樣放。

    我的例子：文章上線前的草稿預覽站。以前用別家的預覽網址，對方手機一點就跳出登入畫面，打不開。

    不讓搜尋引擎找到，不等於上鎖拿到網址的人都看得到，對方轉傳出去，別人也看得到。如果轉傳出去不行，就要加密碼，那就是「替人做事」的網頁了。
    網頁要鎖到什麼程度，我另外排過一個順序
    • 你的網頁其實沒鎖：公開資訊、付費內容、機密隱私該放哪一層　這一段只講「不讓搜尋引擎找到」，那篇把六種鎖法排開，說清楚每一種擋得住什麼。

    要替人做事的網頁：再問事情怎麼進行

    要輸入密碼、存資料、上傳照片、問 AI，就需要廚房。廚房的工作分三種跑法，放的地方不一樣。

    有人按才做，幾秒就好

    登入、送出表單、上傳一張照片、問一次 AI，都屬於這種。沒人按的時候廚房不開火，所以免費額度通常很夠用。廚房裡那一小段程式你不用自己寫，跟 AI 說你要什麼功能就好。

    放哪裡我的例子
    做生意Cloudflare（Pages 加一小段雲端程式），免費起步。要用 Vercel 就要付費版合作單位的課程站（講師、助教、學員看到不同內容）、學員生圖工作站、調香工作坊的香氛卡站
    自己用、實驗Vercel 免費版或 Cloudflare 都可以。AI 用 Next.js 做的網站，放 Vercel 最順我的個人工作台，放 Cloudflare，加一道密碼
    我自己也有一個還沒處理的我的知識官網放在 Vercel 免費版，它介紹付費服務，照規定算做生意。我是整理 37 個網站時才注意到，要搬家還是付費，到現在還沒決定。如果你的 AI 工具已經幫你放上 Vercel：自己用可以沿用，做生意要付費或搬家。
    三家的免費範圍和做生意的規定，我另外整理過
    • 網站放 GitHub、Vercel 還是 Cloudflare？三家免費額度、商用限制與功能差異　那篇把三家的規定原文都列出來。

    時間到了自己做，或 LINE 來訊息就處理

    有些程式不是等人來按，而是自己會動。這種我放 Cloudflare Workers，做生意和自己用都一樣。

    我的例子：萊卡 LINE 群助理。LINE 群裡一有新訊息，它就自動記下來；每五分鐘它還會自己醒來一次，把群裡的照片備份到 Google 雲端硬碟。這些事都在雲端發生，我家裡不用有任何一台電腦開著。

    要注意的是，會一直自動跑的實驗，最好不要跟做生意的網站放在同一個帳號。

    要一直開著，或一跑就好幾分鐘

    一直在網路上抓資料、把影片轉檔、多人同時在線上聊天，這種事沒辦法幾秒結束，廚房要一直開著。Gary Chen 影片推薦 Railway 或 Render。

    放哪裡
    做生意Railway、Render 的付費方案，才能穩定一直開著
    自己用、實驗Railway、Render 的免費方案可以試，但會自己休眠；或放自己家裡的電腦

    我的例子：這一類我沒有放在雲端。我需要長時間跑的工作，例如 9 月初參訪時每小時自動整理我的錄音，是放在家裡的 Mac 上跑。代價我遇過：第一版設定錯了權限，連續失敗十次，當時沒有人發現。

    網頁放上去之後，我踩過的兩個坑

    平台說上線成功，網站的按鈕卻沒反應

    密碼和 AI 的鑰匙不能跟網頁檔案一起上傳，要另外到平台後台設定。我有一次只設了正式網站那一份，測試用的網站一直說「密碼不對」；設好之後，還要再上傳一次才生效。平台顯示成功，只代表檔案傳上去了，網站會不會動，要自己點一遍才知道。

    一個小實驗，拖垮同一個帳號裡的正式網站

    免費額度是整個帳號共用一份，不是一個網站一份。9 月初，我帳號裡一支每幾分鐘就跑一次的檢查程式，把當天的免費額度用完了，同一個帳號裡客戶的網站也跟著存不進資料。這就是為什麼前面一直提醒：實驗和做生意的網站，最好分開帳號。

    判斷不出來，把這段話貼給你的 AI

    把下面這段貼給幫你做網頁的 AI，它會看你的網頁，照這棵樹幫你回答：

    請看這個網頁專案，用我聽得懂的話，依序回答，每題說明你是看到哪裡判斷的：
1. 我先說明用途：這個網頁是【自己用／練習／實驗】還是【做生意：有收費、接案、客戶網站、課程報名、介紹付費服務的官網】。（請你把這格換成我的答案再回答）
2. 訪客打開這個網頁，只是看，還是要替人做事？（要登入、填資料、上傳照片、呼叫 AI、或定時自己跑，都算替人做事）
3. 如果只是看：網址被轉傳出去，別人看到沒關係嗎？要不要被 Google 搜到？
4. 如果要替人做事：事情是有人按才做、幾秒就好，還是時間到了自己做（或接 LINE 這類訊息），還是要一直開著、一跑好幾分鐘？
最後依照「做不做生意」告訴我應該放 GitHub Pages、Cloudflare Pages、Cloudflare Workers、Vercel（免費版或付費版），還是 Railway、Render 這類平台，並提醒我那個平台的免費方案能不能拿來做生意。不確定的地方直接說不確定，不要猜。

    給你的 AI 讀的技術備忘（人可以跳過）

    下面是上面每個判斷背後的技術名詞與查證來源，給 AI 判斷時用。

    • 判斷架構：Q1 商用與否（決定 GitHub Pages 與 Vercel Hobby 是否可用）。Q2 是否需要後端（登入、儲存資料、隱藏 API 金鑰、webhook、排程任一項即需要）。Q3 靜態頁的存取範圍：公開、公開但 noindex、需驗證身分（需驗證即屬後端）。Q4 後端執行模式：事件觸發秒級完成（Serverless）、排程或 webhook、長時間任務或 24 小時常駐。
    • 商用條款：GitHub Pages 條款不允許作為免費主機經營線上生意、電商或商用 SaaS；Vercel Hobby 限個人非商業用途，廣告販售產品或服務即屬商用，商用需 Pro（每月 20 美元起）；Cloudflare 未見同等非商用限制（2026-08-19 查證）。Vercel Hobby 超額時會暫停帳號部署。
    • 靜態頁：Cloudflare Pages 靜態資產請求免費且不計量，免費方案每站 20,000 檔、單檔 25 MiB（2026-09-15 查證）。不收錄＝隨機子網域＋noindex 標頭＋robots.txt 全擋，只管曝光不管存取。GitHub Pages 免費帳號只能從公開 repo 發布（2026-09-16 查證）。
    • 有人按才做：Cloudflare Pages＋Pages Functions；課程站、香氛卡站用 KV，學員生圖工作站用 D1＋R2。Pages Functions 呼叫次數計入 Workers 免費額度。Cloudflare 官方文件建議新專案從 Workers 開始，Pages 仍可用（2026-09-15 查證）。Next.js 專案在 Vercel 支援度最佳；其他全端框架先查官方支援的部署平台。
    • 自己會動：Cloudflare Workers＋Cron Triggers＋D1。萊卡接 LINE webhook 寫入 D1，排程每五分鐘備份照片到 Google Drive。
    • 一直開著：Railway 有免費方案、Hobby 有每月最低費用；Render 免費 Web Service 閒置 15 分鐘休眠（2026-09-16 查證）。
    • 坑一：Cloudflare Pages secrets 分 production 與 preview，設定後需重新部署才生效。
    • 坑二：Workers、D1 免費額度以帳號加總。2026-09-06、07 同帳號高頻檢查程式對無索引資料表全表掃描，用完 D1 每日讀取列數，同帳號其他站寫入失敗；補索引後解決。建議實驗與商用分帳號。
