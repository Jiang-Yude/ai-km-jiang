我為什麼想把 AI 員工搬上雲端

我現在是用 Claude Code 訂閱制，加一台 Mac mini 一直開著跑，這樣其實解決了大部分的問題。卡住的有兩個地方。第一個是我住山區，電和網路都比較不穩，會跳電、會斷網。第二個是這套很難推廣，大部分人不會有一台電腦 24 小時開機。所以我一直在想雲端化這件事。

雲端的做法裡，我覺得實踐得不錯的是 Grok Bot。我很喜歡它的模式：一個 AI 主管管一群 AI 員工，我管的是 AI 員工，不是一件一件的任務。我覺得這樣比較親民。大部分人不是工程師，對管 AI 任務不熟；把它擬人化變成 AI 員工，我現在遇到的很多管理者、創辦人、中高階主管，都有管理員工、培訓員工的經驗，對他們來說比較親切，對我來說也是。

可是 Grok Bot 實在太貴，方案每月 30 美元起。為了減輕它的費用，我都另外接 Claude 和 Gemini 的 API。後來我想，反正都要接 API 了，我缺的只是一個穩定的雲端執行環境，那我何必付 30 美元給 Grok Bot？能不能自己搭一個？Google 有免費的雲端主機可以用；就算不行，也有地方一個月 5 美元左右就租得到雲端電腦。真正執行的算力，都是外接的 API。

所以我請 AI 幫我查了三款可以自己架的開源 Agent，其中 MausBot 就是照 Grok Bot 的 AI 員工團隊模式做的，也一起查要把它們放在哪裡。這篇是上篇，先把我目前遇到的情況和查到的選項整理出來；三款我都還沒用過，之後我會實際做兩個版本：Cloudflare Worker 版，和 Google 免費主機版，實測完寫成下篇，補上實際用的心得。

AI 員工軟體在做什麼：一個住在電腦裡、會自己動手的助理

聊天機器人只會回你話。Agent 多了一雙手：它可以讀寫檔案、執行指令、開網頁、照排程自己做事，做完再回報給你。

先把兩個詞講白話：主機就是 AI 住的那台電腦，可以是你家的電腦，也可以是租來的雲端電腦；API 是讓軟體連上 AI 模型的通道，通常照用量計費，用多少付多少。

這類軟體本身大多免費，真正要花錢的是兩件事：

要花錢的地方是什麼誰來付
AI 模型Agent 的腦袋，例如 Claude、GPT你自己的 API 金鑰，或你已經訂閱的方案
主機Agent 住的那台電腦家裡電腦免費但會停；雲端主機每月幾美元起，Google 也有免費的小台（對外網址、流量另計小錢）

Hermes Agent、MausBot、Pi 各是什麼

Hermes Agent（愛馬仕 AI）：24 小時待命的個人助理

Nous Research 做的開源 Agent，MIT 授權。它的招牌是會把做過的事整理成「技能」，下次遇到同類工作直接拿出來用，用的過程中也會修改這些技能。可以從 Telegram、Discord、Slack、WhatsApp、Signal、Email 跟它說話，也有官方的 LINE 外掛。AI 模型可以接你自己的 API 金鑰，也支援訂閱登入和本機模型。官方文件寫最低 1GB 記憶體、建議 2 到 4GB，要它開瀏覽器至少 2GB。

MausBot（OpenMausBot）：仿 Grok Bot 的開源替代品，一整個 AI 員工團隊

獨立開發者做的開源替代品，跟 xAI 沒有關係，前身叫 OpenGrokBot，Apache 2.0 授權（企業功能的資料夾另有授權）。它在你的電腦上開 Claude Code、Codex 這些官方的命令列工具，所以可以用你已經訂閱的方案登入。每個 bot 有自己的角色、記憶和工作資料夾，有一位「幕僚長」bot 可以建立專家 bot、分派工作，也能排程、互相交接。不想自己顧主機的話，另有付費雲端版，每月 15 美元起，模型費另計。

Pi：極簡的寫程式引擎，也是龍蝦 AI 的核心

Mario Zechner 做的終端機 Agent，MIT 授權。作者最初的設計只有四個工具：讀檔、寫檔、改檔、執行指令，系統提示詞不到 1,000 個 token，其他功能讓使用者自己用擴充套件加。2026 年 10 月 1 日出了 1.0，加進了 MCP 等功能。龍蝦 AI（OpenClaw）就是拿 Pi 當核心做出來的。

網路上用過 Hermes、MausBot、Pi 的人怎麼說

這一段的來源有限這次沒有查到 Reddit 或 Hacker News 上的真人討論串，下面的心得來自部落格和評測站，有些作者跟產品或競品有利害關係，我標在後面。

Hermes Agent：用了三個月的人說生意靠它在跑

  • 有人用了三個月，說研究、寫程式、寫文章、上線都交給它，「整個生意都靠它在跑」。這個網站本身就架在 Hermes 上。（Tony Reviews Things）
  • 有人測了三週，說「越用越熟」的效果在每日研究摘要、程式碼審查、看系統紀錄上看得出來。（Axis Intelligence）
  • 有人算過軟體免費，模型費用每月大約 29 到 251 美元，看你用多少。這位作者在賣競品。（preuve.ai）

MausBot：還在早期，介紹文多、長期心得少

  • 幾乎都是介紹文，還沒有長期使用的心得。
  • 評測提醒的地方：Windows 安裝檔沒有簽章，會跳出警告；Ubuntu 版還是 beta；有一個自動安全掃描站給了警告，那次掃描沒有回報嚴重問題。（AI Profit Boardroom、SkillsLLM）
  • 價格說法互相矛盾，有寫免費、有寫付費，以官網為準。

Pi：作者因為對 Claude Code 不滿才自己做

  • 作者 Mario Zechner 的不滿是工具的行為慢慢變了，又看不到它到底讀進了什麼。（作者自己的文章）
  • 有人實測同一個一個字的指令，Pi 用了大約 1,358 個 token 的上下文，Claude Code 用了大約 31,012 個，這是該文作者自己的單次實測。（DEV Community）
  • 有評測文建議 Pi 跟 Claude Code 搭著用，因為 Pi 沒有子代理，安全設定也比較少。（Composio）

四個問題點下去，看你該先試哪一款

先回答它要幫你做什麼、你願不願意自己顧主機，再回答你想用什麼跟它說話，答案通常只剩一款。這棵樹只是起點：要從 LINE 交辦寫程式的工作，或要好幾個 AI 員工分工又想用聊天軟體下指令，就把兩個終點的條件都看過再決定。

點點看：你的 AI 員工該裝哪一套一題一題點答案，最後會看到建議、理由和我自己的例子。
    決策樹文字版
    1. 它只要被人找的時候回一句、查一下資料就好嗎？是：不用裝 Agent，用 Cloudflare Worker 這類雲端小程式直接接 Claude API；不是，要自己動手做事：看第 2 題
    2. 你願意自己顧一台主機嗎（安裝、更新、壞了自己修）？不想：付費託管版，例如 Grok Bot 或 MausBot 雲端版（先核對聊天入口、資料放哪國、預算，不符合就找人代管）；願意：看第 3 題
    3. 要它做的事主要是寫程式，還是處理日常工作？寫程式、在終端機直接操作：Pi，或你已經在用的 Claude Code；日常工作，或想從手機聊天軟體交辦寫程式：看第 4 題
    4. 你想用什麼跟它說話？LINE、Telegram 這類聊天軟體：Hermes Agent；一個專門的 App，裡面好幾個 AI 員工各管一件事：MausBot（主機要 4GB 以上，比較小就選 Hermes Agent）

    你的狀況第一步
    不懂技術，只想要一個隨時能交辦的 AI 員工先不用租主機。把下面「貼給你的 AI」那段話貼給 ChatGPT 或 Claude，或請熟悉的人陪你照決策樹走一次，選好再動手
    用過 Claude Code 或 Codex，想自己架先在你現有的電腦裝決策樹選出來的那一款，試一週；模型費用先查服務商能不能設成「到額度就停用」，只能寄提醒的話，自己另外訂一個停止的條件；確定每天真的會用，再搬到 Google 免費主機或便宜的雲端主機

    選好軟體，接著選它住的地方。差別在記憶體夠不夠、會不會停，還有每月要不要付錢。

    放哪裡每月大約適合要注意
    家裡的電腦（例如 Mac mini）0 元先試試看、偶爾停掉沒關係跳電、斷網就停；Agent 碰得到你電腦裡的檔案
    Google Cloud 免費主機（e2-micro）主機 0 元，但預設配的對外 IP 每月約 3.65 美元，流量超出免費額度另計先試 Hermes、Pi 不開瀏覽器的輕量用法只有 1GB 記憶體，作業系統也要吃一點，長期開著可能不夠；機房只能選美國三區，要綁信用卡

    Cloudflare 這類雲端小程式免費額度起被找才回應、照排程分幾步做完的小任務沒辦法像一般主機那樣一直開著跑任意程式，也不能裝軟體

    不裝 Agent 也可以：用 Cloudflare Worker 直接接 Claude API

    還有第四種做法，不裝上面任何一款。Cloudflare Worker 是放在 Cloudflare 上的小程式，平常不佔一台電腦，有人呼叫它、或排程時間到了才醒來。它醒來後把訊息交給 Claude API，拿到回答再送回去，做完就停。

    這種做法要自己寫程式，或請 AI 幫你寫。Claude 能用哪些功能、能做多少事，看你寫了什麼。你可以寫成固定流程，也可以把幾個功能交給 Claude，讓它自己決定下一步要用哪一個。

    Cloudflare Worker 直接接 Claude API自己架 Agent（Hermes、MausBot、Pi）
    要不要一台一直開著的主機不用，Cloudflare 幫你跑要隨時接單的話，要有一台一直開著的電腦，家裡的或租來的
    每月固定費用免費方案整個帳號合計每天十萬次請求，每次執行的 CPU 時間上限 10 毫秒（等 Claude 回應的時間不算），資料庫另有額度；Claude API 照用量另計家裡電腦只有電費；租雲端主機照方案計價，本文查到的 Hetzner CX23（2 核 4GB）每月約 7 美元；再加模型費用
    能做什麼收訊息、照排程查東西、呼叫 Claude 寫回覆、把資料存進 Cloudflare 的資料庫看你給它哪些工具和權限，讀寫檔案、執行指令、開瀏覽器、裝軟體都做得到，Agent 自己決定下一步
    做不到的事不能像一般主機那樣隨意安裝軟體、碰不到你電腦裡的檔案；要開瀏覽器得另接雲端瀏覽器服務，例如 Cloudflare 自己的；每一次執行能做的事有上限主機停了它就停
    誰來設計流程你（或你的 AI）事先寫好固定的流程，和 Claude 可以用的功能Agent 自己判斷，你給目標和規則
    適合固定流程：被標註就回覆、定時查一下再通知你每次都不太一樣、要動手做的工作

    我想讓朵拉 AI 兩種一起用：在 Threads 標註朵拉，雲端的 Claude API 先回，簡單的、已經知道的直接回；需要電腦安裝測試的才叫家裡的 Mac mini，Mac mini 沒開，就先回「電腦沒開，先把需求記著，重開之後再幫你測試」。目前 Cloudflare Worker 版已經做好，還在試跑，只寫稿不發出去；電腦沒開時要回的那句話，還要再改成這個意思。朵拉官網右下角的小客服也是用 Cloudflare 接 Claude API，接的是比較便宜的 Claude Haiku 模型，回答訪客問題，已經正式在用。

    想讓 AI 員工住在 LINE 裡，三款只有 Hermes 有官方外掛

    Hermes Agent 走 LINE 官方的 Messaging API。你要在 LINE 後台填一個公開的 HTTPS 網址（webhook），LINE 收到訊息才會轉給 Hermes，所以光是收文字就需要這個網址；要傳圖片、語音、影片給你，還要再設定一個媒體用的公開網址參數，通常沿用同一個 HTTPS 網址就可以。費用上，用回覆的方式（Reply）回訊息不計入官方帳號的訊息額度，但回覆有時間限制；用主動推播（Push）就會計入，就算內容是在回答對方也一樣。龍蝦 AI（OpenClaw）也有 LINE 頻道。MausBot 和 Pi 目前都沒有。

    一個 LINE 官方帳號只能填一個 webhook 網址如果你的官方帳號已經接了別的 bot，直接改接 Hermes，原本那個就會停。要一個帳號同時接兩套，得自己做一個中介服務幫忙分流，還要處理訊息驗證和重複訊息。剛開始比較簡單的做法是另外開一個新的官方帳號給它。
    AI 該住在哪個通訊軟體，我另外比過
    • 通訊軟體 AI 友善度比較：LINE、Telegram、Discord、Slack：這一段只講 LINE 怎麼接 Hermes，那篇比四個平台對 AI 員工的友善程度

    自己架 AI 員工前要想清楚的四個風險

    主機再穩，帳號被卡住也一樣會停朵拉 AI 在 Threads 被標註就回覆的程式，現在跑在家裡的 Mac mini。11 月 10 日查的時候發現，朵拉的 Threads 帳號被平台卡在驗證關卡，程式連不上，最後一次成功回覆停在 10 月 23 日，之後就沒有再回過標註。換到 24 小時的主機，解決的是「電腦停了」；帳號被鎖、金鑰過期、額度用完，還是會讓它停。所以不管放哪裡，都要有辦法知道它停了。最簡單的做法：叫它每天固定時間在 LINE 或 Telegram 回你一句「我還在」，哪天沒收到就去檢查。收到了也只代表報平安這條路是通的，像朵拉這種帳號被卡住的狀況，還要另外看它最後一次成功回覆是什麼時候。
    風險會發生什麼怎麼降低
    金鑰外洩MausBot 命令列版把 API 金鑰用明文存在主機的設定檔（桌面版改存作業系統的安全儲存區）；主機被入侵，金鑰就被拿走給 Agent 專用的金鑰並設用量上限，主機只開必要的連線
    權限太大Agent 通常能做的事等於執行它的那個帳號，Pi 預設也沒有沙箱；那個帳號碰得到的檔案，它都碰得到放在專用主機或專用帳號裡，不要跟你的工作資料放在一起
    費用失控模型 API 照用量計費，Agent 一直跑就一直花先查服務商能不能設成到額度就停用，只能寄提醒的話自己訂停止條件；第一週每天看一次用量
    客戶資料放錯地方Google 免費主機只能選美國機房；幫客戶架的話，客戶資料會存在國外的主機上先問客戶資料能不能出國、誰負責維護、出事誰處理，談清楚再選主機

    • API key 可以貼給 AI 嗎？：這一段只提醒金鑰會外洩，那篇講怎麼存進 Mac 鑰匙圈讓程式自己去拿

    給你的 AI 讀的技術備忘（人可以跳過）

    • Hermes Agent：官方 LINE 設定文件。LINE 走 hermes gateway setup 選 LINE，webhook 路徑 /line/webhook，傳媒體要設 LINE_PUBLIC_URL，群組白名單 LINE_ALLOWED_GROUPS。
    • MausBot：github.com/milind-soni/OpenMausBot。無介面主機可用 npx openmausbot serve（需 Node 24 以上），repo 附 Dockerfile 與 compose.yaml；命令列與無介面版的金鑰用明文存在 ~/.openmausbot/config.json（權限 0600），桌面版存在作業系統的安全儲存區。
    • Pi：npm 套件已改名到 @earendil-works/pi-coding-agent（舊名 @mariozechner/pi-coding-agent）；最初設計的內建工具是 read、write、edit、bash，1.0（2026-10-01）加入 MCP。
    • Google Cloud 免費方案：每月一整個月份的 e2-micro 時數（約等於一台），限 us-west1、us-central1、us-east1，30GB 標準永久磁碟；使用中的對外 IPv4 每小時 0.005 美元，不在免費範圍，整月約 3.65 美元。
    • Hetzner：德國、芬蘭機房 CX23（2 vCPU、4GB）含 IPv4 每月 5.99 歐元（約 7.09 美元），未稅；2026 年 11 月查時這個系列顯示缺貨。
    • Hermes 記憶體：官方 Docker 文件最低 1GB、建議 2 到 4GB，開瀏覽器至少 2GB。
    • 價格與方案常變，以各家官方頁面為準。
