講師工作流 × 知識管理

講師如何用知識管理流程，把備課變成可複用系統

從找資料、靈感池、課前問卷、開課前推廣、備課、交付品、課後再製，到跨課程複用。這套流程讓每次上課都餵養下一次，不只產出一份簡報。

發佈 2026-05-23 ｜ 最後更新 2026-05-23

這篇在講什麼

這篇整理的是「講師的 Agent 工作流」背後的知識管理流程。它從簡報製作切入，延伸到一個講師如何把平常看到的資料、學員問題、社群回饋、課前問卷、課後逐字稿，都變成下一次備課時可以直接調用的素材。

適合誰

· 講師、顧問、老師、內容創作者，常要把同一組知識講給不同對象
· 平常素材很多，但真正要備課時還是找不到、串不起來的人
· 想用 Agent 幫忙備課，但不想只停在「幫我做一份簡報」的人

你可以帶走什麼

· 一套講師備課的八階段知識管理流程
· 看懂靈感池、課前問卷、課後再製、跨課程複用如何接起來
· 一種把每次講課變成下一次可重用素材的方法

這篇和前一篇的差別：前一篇講「課前問卷到簡報」這個新手示範；這篇把鏡頭拉大，看講師如何把整個備課生命週期變成知識管理系統。

八階段流程：從素材到可複用系統

這堂課把講師工作流拆成八段。每一段都會產生下一次能再用的知識資產，不只服務當下任務。

01找資料

用多代理交叉，讓不同角度的資料先被找齊，不只順著單一脈絡走。

02靈感池

平常看到案例、回饋、問題就記下來，用標籤穿針連回未來課程。

03課前問卷

不只問想學什麼，更問現在卡在哪一步，讓備課有真實落點。

04開課前推廣

推廣文案、分鏡、留言回饋都會反過來校準正式課程。

05備課

用標籤和反向連結，把平常累積的素材聚成一束，再讓 AI 順稿。

06交付品

投影片、網頁簡報、講義和範例，都要可保存、可分享、可被 AI 讀取。

07課後再製

逐字稿、學員提問、講得順不順，都回收成下一次可用素材。

08跨課程複用

把有效流程寫成技能包，把知識拆成卡片，面對不同對象重新組合。

找資料：不要讓一個 AI 順著同一個方向找

AI 找資料很容易被上下文帶偏。你問它某場發布會評價，它可能先找到官方資料，接著整段脈絡都被官方說法帶著走。

課程裡的做法是多代理交叉：讓不同子代理分別找官方資料、正面觀點、負面觀點，再把來源和原文摘錄拉回來交叉比對。AI 不負責直接下結論，先負責把資料找齊、把來源列清楚。

這件事對講師很重要。因為備課時最怕的是你只看到自己本來就相信的資料，然後把這份偏好包成課程內容。多代理交叉的價值，是讓你在備課前先看到不同角度。

整理分類和靈感池

講師平常看到一個好例子、聽到一句學員問題、讀到一個趨勢，不一定當下就會用到。但如果沒有在當下記下來，等到真正要備課時，很難再想起來。

這堂課把這件事講成三個動作：平時累積、標籤穿針、定時總結。

平時累積不是只把內容存起來，還要記下當下為什麼覺得它有用。標籤穿針是用通用標籤和場次標籤，把素材連到未來可能會用到的課程。定時總結則是建立節奏，讓資料不會拖太久才整理。

標籤的兩層「講師工作流」是通用標籤，未來所有講師相關課程都能用；「2026-05-23 課程」是場次標籤，只服務這一堂課。兩層一起下，未來備課時可以撈主題，也可以撈場次。

課前問卷：把想學什麼改成卡在哪一步

很多課前問卷會問：「你想學什麼？」但學員有時候也不知道自己想學什麼。

課程裡更重視的是問：「你現在卡在哪一步？」

這種問法比較接近真實需求調查。學員不一定能說出完整解法，但通常知道自己卡在什麼地方。講師拿到問卷後，可以用 Agent 做落點分析，看學員集中在哪幾類程度、哪幾種需求。

這會改變備課方式。講師設計課程前，可以先看這群人真正卡在哪，再回頭校準自己的假設。核心區先處理大多數人的問題，補充區再處理少數延伸需求。

開課前推廣，也是備課的一部分

開課前推廣不是只為了招生，也是在測試受眾怎麼理解這個主題。

課程裡提到社群輪播卡的流程：先寫文案，再生成分鏡腳本，最後才生圖。文案是骨幹，分鏡是橋樑，圖是肉。

這套流程背後的知識管理意義是：每一次推廣都會產生回饋。有人在留言問「會不會教某個問題」，這類訊號可以變成備課素材。它可以被放回靈感池，也可以改變正式課程的開場方式。

如果講師有固定品牌角色或視覺風格，像咪卡這種角色，也要把風格定義、三視圖、常用分鏡原則保存下來。這些資料會讓下一次圖文教學保持一致。

備課：用標籤把素材聚成一束

真正備課時，關鍵是把平常已經標記過的素材聚在一起，不必從零開始想。

課程裡舉的做法是：到了備課當天，打開講座檢索頁，用 backlinks 或標籤把相關素材拉出來，例如「講師工作流」「2026-05-23 課程」。這些素材可能是工作日記、半成品文章、學員回饋、社群留言、前一堂課的問答。

接著再讓 AI 順稿。AI 可以處理語感、節奏、過渡；講師自己負責立場和取捨。

新手模擬器如果主題對講師很熟、對學員很陌生，就讓 AI 先扮演新手試聽一輪，找出哪些地方講師以為理所當然，但學員可能完全不懂。

做交付品：讓成品可以保存、分享、被 AI 讀取

交付品可以是投影片、網頁簡報、課後講義、範例檔、提示詞，也可以是完整的教學手冊。

課程中用網頁簡報作為示範，重點放在交付品要可保存、可分享、可被 AI 讀取。這也是為什麼用 HTML 簡報有價值：它能投影，也能成為一份可以被搜尋、被回收、被下一次 Agent 使用的素材。

公開內容可以放 GitHub Pages。含有會議紀錄、客戶報告、個資或敏感內容的，就要走半私密部署或不要公開。

課後再製：留下細節，不只做摘要

課後真正重要的是把課堂中發生的細節保存下來，不要只做一份摘要。

這堂課提到逐字稿三層次整理：超詳細、很詳細、1 比 1。它的價值不只在內容整理，也在洞察層。你可以讓 AI 分析自己哪裡講得順、哪裡不順，哪些段落學員反應好，哪些地方需要重講。

課後還可以做教學手冊，把講師自己的講義整理成別人也能接手教的版本。學員提問也可以一題一題入庫，連回下次同主題課的檢索頁。

這樣一來，學員問題會從課堂互動延伸成下一次備課最好的素材。

跨課程複用：把課程變成積木

當前面七段都留下來，講師就不需要每次從零開始。

一次成功的操作，可以寫成技能包；一組穩定的講法，可以拆成卡片；一批學員問題，可以變成下次課程的 FAQ；一份逐字稿，可以變成教學手冊或深度文章。

課程裡用積木來比喻：卡片化的知識，可以按照下一場課的需求重新排列組合。同樣一組知識，面對大學教授、行政人員、內容創作者、小編或企業主管，講法可以不同，但底層素材可以共用。

核心講師不用每次重新出發。讓每次講過的課、收過的問題、做過的交付品，都變成下一次可以被 Agent 讀取、整理、重組的材料。
