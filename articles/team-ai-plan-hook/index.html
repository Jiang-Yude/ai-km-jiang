AI 工作流 / 公司導入

公司訂了 ChatGPT 商務版或 Claude Team，員工用 AI 做的東西就會留在公司嗎？

商務版管什麼、不管什麼，什麼情況選哪一個｜公司資產、共用知識庫、Codex、Hook

先講答案

不會自動回到公司手上。

訂了商務版或團隊版，公司控管的主要是使用權限：誰可以用、公司統一付款、員工離職時把他的權限移除。

員工用 AI 做出來的檔案和文件是另一回事。假設他在自己的電腦上用 Codex，做出來的東西還是存在他自己那台電腦上。他若是沒有回報，這個資產就沒有回到公司。

所以最終還是要有一個雲端硬碟，或是一個共同的知識庫。兩家方案都有共享專案這類協作功能，但共用的知識庫，不會因為你買了商務版或團隊版就自動出現，員工的成果也不會自動整理進去。

（這裡講的「資產」，是公司手上拿得到、用得到的成果。法律上，兩家的商業條款都約定 AI 的輸出歸訂約的公司所有；但員工跟公司之間怎麼約定，仍要看雙方契約。）

這篇分三個部分講：商務版到底管什麼、公司真正要的成果要怎麼管、ChatGPT 商務版和 Claude Team 什麼情況選哪一個。

這個問題從哪裡來

一位設計公司老闆問我，團隊該訂哪一種 AI 方案。聊到後來，他真正的需求是：「把公司的 AI 跟個人的 AI 分開。」

很多老闆會接著問兩個問題：

  • 我訂閱商務版，就可以完全控管員工在公司做的東西嗎？
  • 員工做的這些東西、這些知識經驗，自動就會變成我的資產了嗎？

兩題的答案都在上面那一段。下面把它拆開來講清楚。

商務版管什麼、不管什麼

先說兩個名詞。Codex 和 Claude Code 是兩家各自「在電腦上直接讀寫資料夾的 AI」。ChatGPT 商務版（Business，以前叫 Team）包含 Codex，Claude Team 每個席位都包含 Claude Code。

商務版、團隊版有管商務版、團隊版沒管
帳號誰可以用公司的 AI，由公司控管
離職公司可以移除離職員工的工作區權限他做過的成果有沒有留在公司
資料訓練兩家都預設不拿公司的內容去訓練模型
對話內容ChatGPT 商務版的管理員，預設看不到成員的私人對話
協作有共享專案這類功能，大家可以放進同一個地方不會自動把員工的成果放進去
AI 做出來的檔案在員工電腦上用 Codex、Claude Code，檔案存在它工作的那個資料夾，可能就是員工自己的電腦
共用知識庫不會因為買了商務版或團隊版就自動整理出來
一句話整理商務版管的是「使用權限」。公司要的成果和知識，要另外管。

有些老闆以為，買了商務版，就可以完全控管員工用 AI 做事，公司所有的資產、流程都可以自動管好。並沒有。

商務版管的只有使用權限：誰能用、誰付錢、員工離職時把他移除。員工跟 AI 的對話不會自動被整理，知識、經驗、技能包不會自動被提煉出來，做出來的成果也不會自動收回公司。

尤其是用 Codex、Claude Code 這種 agent，檔案就存在員工自己的電腦上。公司的資產和流程，要公司自己管。

公司的成果要怎麼管

我給那位老闆的提醒是：帳號分開了，檔案也要分開。

公司的事，在公司的資料夾裡做，例如公司的 NAS（公司放檔案的網路硬碟）。這樣資料才會集中留在公司。

原因很單純。在電腦上用 Codex、Claude Code 時，做出來的檔案就存在它工作的那個資料夾。它在員工自己的電腦上工作，檔案就留在員工的電腦；它在公司的資料夾裡工作，檔案就留在公司。

所以要讓成果回到公司，要先有一個大家共用的地方：雲端硬碟、NAS，或是一個共同的知識庫。這個地方要公司自己準備，商務版不會附給你。

什麼情況選哪一個

上面講的資產問題，兩家的答案一樣，所以它不影響你選哪一家。選哪一家，看的是團隊的習慣和你對規矩的要求。

你的情況可以怎麼選原因
團隊大部分人習慣用 GPT可以先買 ChatGPT 商務版試試看大部分人本來就習慣用 GPT
很多事一定要照你的流程規劃去運作，要 AI 嚴格守規矩，而且有人能設定、測試 Hook我個人會推薦 Claude 的商務版（Claude Team）要嚴格守規矩，還是 Claude Code 的 Hook 保險
兩種需求都有兩個都買也可以兩家互不包含，各自訂閱

要注意，這張表講的是我的使用經驗和推薦，兩家各有適合的情況。

兩家的個性差在哪、為什麼守規矩的工作我推薦 Claude，我另外寫了一篇：〈ChatGPT 和 Claude 該選哪個？〉。

「席位」是一個員工用一個位子。

兩家官網的美元標價相同，標價不會是決定因素；但用量限制、超量怎麼計費、導入要花多少功夫，還是要比較。要注意的是兩家互不包含：訂了 ChatGPT 商務版不會有 Claude Code，訂了 Claude Team 也不會有 Codex。

價格會調整，訂之前以兩家官網為準。

為什麼要守規矩的公司我推薦 Claude：Hook

我覺得 Claude 最被小看的，是 Hook 機制。

什麼是 Hook？就是 AI 要執行你設定的那些動作之前（例如寫檔案、下指令），先由程式檢查一次，不照規矩就直接擋下來。規矩寫在提示詞裡，AI 大部分時候會照做，但會漏；Hook 不靠 AI 自己記得。

很多老闆要求很多事一定要照他的流程規劃去運作。Hook 就是用來守這種規矩的機制。

舉我自己的例子：我的知識庫裡，工作日誌一定要上傳，心情日記一定不上傳。這種「一定要」和「一定不」的規矩，就是交給 Hook 守。

套到公司也一樣，例如檔案一定要存進 NAS。前面講的「成果要留在公司」，就可以用 Hook 把它變成關卡，不只靠員工記得。不過 Hook 只管 AI 在 Claude Code 裡的動作，員工自己在別的程式裡存檔，它管不到。

GPT 目前也有類似的 Hook 機制，Codex 有自己的 Hook。但就我目前來看，穩定性沒有 Claude Code 的 Hook 高。要嚴格守規矩，還是 Claude Code 的 Hook 保險。

用 Hook 之前要知道三件事

  1. Hook 只在 Claude Code 裡運作。訂了 Claude Team 不會自動就有規矩。
  2. 要有人設定和測試。規矩要先寫好、設定好、測過。
  3. 兩家都有漏擋的回報。Claude Code 的 GitHub 上有一則漏擋回報（issue #32990 ↗），因為久未活動被關閉；Claude Code 現在另有「檢查程式失敗就擋下」的設定可以開（官方 Hook 文件 ↗）。Codex 的 GitHub 上也有一則（issue #27833 ↗），目前還開著。個案不代表整體，所以設定完一定要測試。

問 AI 選方案之前，先給它你的工作流

你也可以自己問 AI 該選哪個方案。問哪家 AI 都可以，前提是它要知道你的工作流。

就像問設計師，要先給他房屋的格局、照片、設計圖。否則設計師也只能瞎掰。

整理：三句話帶走

  1. 商務版管的主要是使用權限。員工的成果不會自動回到公司手上，共用的知識庫也不會自動整理出來。
  2. 帳號分開了，檔案也要分開。公司的事在公司的資料夾裡做，成果才會留在公司。
  3. 選哪一家看習慣和規矩。大部分人習慣用 GPT，可以先買 GPT 的商務版試試看；要 AI 嚴格守規矩，我個人推薦 Claude 的商務版；兩個都買也可以。
