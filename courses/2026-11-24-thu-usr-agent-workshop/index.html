為什麼這樣設計

  • 三小時先聚焦一件事：時間只有三小時，先集中在 Agent 的操作，不把服務創新案例跟 LINE 串接硬塞在一起。
  • 先從操作開始：目前遇到的大部分人，還不太會讓 Agent 幫自己操作電腦跟網頁。實體課最能直接帶的就是操作，大家熟悉之後，其他應用或機制設計可以再加開線上課程補上。
  • 中間抓兩小時做串接：這件事上下限差很多。已經習慣用 Agent 做事的人，十幾二十分鐘就好；還沒有 Agent 概念的人，可能要兩三個小時。保險起見抓兩小時，剩下的時間講概念跟應用。
  • 用 LINE 示範：LINE 是大家最常用、最基本的工具。教的其實是 Agent 串工具的原理，理解之後不只 LINE，各種工具都可以串。
  • 自己動手串：自己的 LINE、行事曆、雲端硬碟資料，掌握在自己手裡比較安全。
  • 建議用桌面版：網頁版 AI 不能自己把程式碼貼上，出問題要整份重寫再自己複製貼上；桌面版可以直接幫你操作，會順很多。
