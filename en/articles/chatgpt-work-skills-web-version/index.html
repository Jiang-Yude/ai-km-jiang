First Understand Three Terms: ChatGPT, Codex, Work

Before Discussing Skill Packages, First Clarify Three Frequently Confused Terms Together.

ChatGPT (Web Version)

The chat window everyone is most familiar with, which can chat with you and answer questions, has been around for a long time.

Codex

The ChatGPT installed on your computer can access your folders, read your files, and generate documents. It has now been merged with ChatGPT. It's powerful, but it's often difficult to install on old Windows and non-M series old Macs, so many people are stuck at the gate.

ChatGPT Work

The main subject of this article. It's a mode in the web version of ChatGPT, where you can click on the new conversation above to see Chat and Work. The difference will be explained in the next paragraph.

Current version status If you're using the free version, you can only use Work in the desktop version of ChatGPT, which actually has little meaning because if you already have the desktop version, you can just use the desktop version directly. If you want to use Work in the web version, you currently need the paid version, which costs 690 yuan per month.

The main significance of the Work mode: the web version of ChatGPT can finally use skill packages.

Work can create websites, and the content you see in this article was made using it during a lecture. But I think the most important thing about its appearance is that it finally allows the web version of AI to use skill packages.

Before this, there were only two web versions that could use skill packages: one is Claude, and the other is Grok from Musk. But these two are rarely used, and Claude is very expensive, with no less than a hundred dollars per month, which is unaffordable. So I've been stuck in promoting skill packages for the past few years: a useful tool, but people's tools can't use it.

Now, the web version of ChatGPT, which is the most familiar and has the lowest threshold, finally supports skill packages.

There is also an added advantage. The Work mode of the web version of ChatGPT can use skill packages. It can also be used together with 'projects'. Projects place source data. Skill packages place your judgment. Combining these two elements will result in something more useful. The next paragraph explains how to combine them.

If you are already using Codex and are familiar with skill packages, continue to use your Codex, there's no need to move it over specially. This article is written for those who 'have always wanted to use skill packages but the tools don't allow it'.

Prompt words it listens to or not, skill packages are the operation manual.

The term 'skill package' is still unknown to many people, so first clearly explain the most core thing.

We used to teach AI to do things using prompt words. But have you ever had an experience: even after giving prompt words, the AI just listens or doesn't listen, sometimes it doesn't even care about you.

Skill packages are different. It's more like an operation manual, with more rigorous SOP. You can think of it as a new protocol or a formal contract. When the AI sees this contract or this operation manual, it will take it more seriously and follow it.

First, make it clear Skill packages are not 'absolutely' compliant. Large model AI is essentially a probabilistic model, so it will still have some small problems. But compared to prompt words, it has more constraints and will follow your needs more.
Remember this in one sentence Supporting skill packages and not supporting skill packages are two different AIs: one that listens and one that doesn't.

Best practice for public domain documents: store projects in the data repository, and store judgment in the skill package

People often ask me: can AI generate public domain documents in the format I want, reliably? For example, documents that conform to international standards or company-specific standards like reports.

Yes. This applies to documents, images, and presentations. I recommend combining projects with skill packages; this combination is the best one.

What is a project? Whether you use the free or paid version, you can now use projects. Think of it as a folder. A topic, a series, everything is stored in the same folder. For example, if I need to communicate with A vendor, I create a 'A vendor' project, and put background information, presentations, and meeting records into it. Over time, this folder will be filled with the complete context of A vendor, and every time I ask it to handle matters related to A vendor, it can understand the background and context.

How do projects and skill packages divide responsibilities? I will explain with my actual experience. Every time I write an article, I chat with AI. Suppose I have revised an article ten times until I am satisfied. What does this mean? It means the tenth version is the correct one, and the first nine are incorrect versions. The characteristic of a project folder is that all conversations are stored inside. The advantage is that all data is available, but the disadvantage is that the correct version is inside, along with incorrect versions and off-topic discussions. What should I do? There are two approaches.

Approach 1: Be more diligent

Every time I reach the correct answer, I copy the final version and manually move it into the project's data source. The limitation is that the data source can only store about ten versions, even in the paid version.

Approach 2: Better

Directly ask AI to help me, and organize the articles, patterns, formats, and judgments I consider correct into a skill package. The skill package stores the most refined steps, rules, and judgments, while the data source stores supporting reference materials. The two sides cross-verify, and the output is both stable and accurate.

Summary of the division of responsibilities in one sentence Store data in projects, and store judgment in skill packages.

Lecture demonstration: if you don't know how to create a skill package, don't worry, ChatGPT can do it

Many people are afraid to hear 'create a skill package' and think it is the job of engineers. Don't worry, if you don't know how to do it, ChatGPT can do it.

In my lecture, I demonstrated a 'Mika Community Image Card Skill Package' (Mika is my AI brand image). The method is to tell ChatGPT all the things I say when I modify images. I roughly explain it like this:

In the future, I will give you an article, and you will help me create a community carousel card. Before generating the image, give me a storyboard script, don't generate directly. The number of images is up to you to judge. For simple topics, about three to five images, for content-rich topics, seven to ten images. The ratio is 4×5, because it can also be used on IG. Each image should have a headline, subheadline, content, and layout. The image of Mika should be generated according to the three-view model in the reference materials, don't generate other images. The actions of Mika should not be the same in every image, they should match the context of each card.

After saying all that, I said: help me create the Mika Community Image Card Skill Package. It then wrote it down and saved it. This demonstration brought out three principles, which are more valuable than the skill package itself.

Principle 01 Unable to express rules? Let AI help you synthesize them

I don't do design, but I have done ten plans. I gave them all to it and said, 'I want to create a skill package. First, help me extract the rules from it, and first tell me how you plan to synthesize them.' If I am not satisfied, I can directly modify it. For example, changing 'seven to ten images' to flexible judgment, adding a hard rule: don't split or pad for the sake of quantity. This image is only worth two images, so give me two.

Principle 02 Talk about both good and bad, and remember to ask it to update

If it produces something great, say 'This style is great, remember it.' If it doesn't, say 'This won't do, you need to change it.' Key point: currently it won't automatically write the correction back to the skill package, so you need to remember to add a sentence 'Update this to the skill package.' These rules are the result of accumulated experience.

Mindset 03 Learn to be a boss

You are originally the boss, so take out your most habitual side of yourself. Tell the AI things you usually do not dare tell your employees. If you are an employee, recall the strict yet reasonable managers who made your work smooth and how they required you to operate. Then, require the AI in that same manner.

At the end of the demonstration, I added one more test. I gave it an older published article and said, "Help me create a set of visual posts." I had already told it to provide the script first, so I checked whether it remembered. It provided the script first, suggested making six images, and passed the test. This is the skill package in action: it turns my long explanation into an operating manual the AI can follow.

Two pitfalls: when to switch from the web version to the desktop version

The above are all the benefits. But when I used 'project plus skill package' deeply, I hit two unavoidable pitfalls. Let me tell you first, so you won't find out by stepping on them.

Pitfall 1: Cross-project inaccessibility

A vendor's content is locked in folder A. One day I wanted to start a new project, and asked it to take 1, 2, 3 from A, 4, 5, 6 from B, and 7, 8, 9 from C, to form a new one. It couldn't do it. The content was clearly ready in my project, but it just couldn't access across folders, so I had to pick them one by one.

Pitfall 2: Physical limitations of the web version

When the skill package reaches about 6000 characters or more, calling it to update is likely to cause problems; exceeding 10,000 characters, the problems become much more. Three years of planning, government-related, event-related, various courses, cases of various lecturers and clients, just adding them up easily exceeds 10,000 characters. A single web page has a memory limit, and it can't sustain it.

What to do Use the desktop version, storing the skill package and data on your computer, which is much better than the web version.

But I need to be fair: if you usually just run small projects, the skill package won't reach several thousand to tens of thousands of characters, and you won't have so many complex, cross-domain integration projects. In that case, the web version's Work plus project can be used very happily. These two pitfalls are only encountered when using it deeply. Start with the web version, hit the wall, then consider moving to the desktop version Codex. By then, you've already mastered the logic of the skill package.

Tools will change, the skill package is your asset

Going back to the feeling I mentioned at the beginning, using AI is like being its assistant. The skill package is the tool that turns this relationship back. You store each judgment and correction into the skill package, and the AI becomes a tool that listens and follows, turning it from a chatbot that doesn't always listen into an employee who understands your rules and follows your standards.

Tools will keep changing. Today it's ChatGPT Work, tomorrow it might be something else. But the skill package is your asset. It can be downloaded and moved to another AI to continue using. Instead of relearning every time you switch tools, establish clear rules: no matter which AI comes to work, it follows your process.

This is what I've been teaching all along. Choose a tool that suits you. The real effort is turning your experience into an operational manual that the AI can understand and execute.
