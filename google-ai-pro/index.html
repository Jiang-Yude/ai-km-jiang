我當初訂 Google AI Pro，主要是為了 Google Meet，平常也會用到雲端硬碟。Gemini 聊天本身我沒有太常用，因為我覺得目前不太合手。但訂閱費已經付了，如果剩下的算力、開發工具、語音和創作額度都放著，確實很浪費。江江教練

本頁是江江教練整理的非官方指南，與 Google 沒有合作或隸屬關係。

你的帳號實際有多少額度，要登入各服務自己看。本頁整理的是官方公開資訊，功能、額度、價格與開放地區會變，以官方頁為準。

寫信、寫文件、開會

在平常就在用的 Gmail、Docs 與 Meet 裡叫出 Gemini。

Gmail、Docs 裡可以直接叫 Gemini；Meet 會議筆記目前不支援中文會議。

要錢嗎

限制
會議筆記沒有中文；Meet 不在權益說明頁

Gmail、Docs、Meet 右上角

AI Pro 給你什麼

  • Gmail、Docs、Vids 等服務裡的 Gemini，可用功能依方案而不同。
  • Meet 的「Take notes for me」會議筆記：Meet 說明頁寫需要符合資格的 Workspace 版本或 Google AI 方案。

怎麼開始

  • 在 Gmail、Docs 裡找 Gemini 的入口。
  • Meet 開會時，點右上角「Take notes for me」。筆記會在會後存到主持人雲端硬碟的「Google Meet」資料夾。

要注意

  • Meet 說明頁列出的會議筆記支援語言是英文、法文、德文、義大利文、日文、韓文、葡萄牙文、西班牙文，目前沒有中文。
  • AI Pro 權益說明頁沒有列出 Meet。哪些 Meet 功能算在你的方案裡，請進 Meet 確認。

做影片、圖片、音樂

概念影片、圖片、配樂，或把照片變成短影片。

Flow 每月多 1,000 點做影片圖片，Flow Music 每月 10,000 點做音樂，點數不累積。

要錢嗎
點數內含，用完要加購
限制
相簿功能只在選定國家
從哪開始
Flow、Gemini app、Google 相簿

AI Pro 給你什麼

  • Flow：所有人每天有 50 點，AI Pro 每月另加 1,000 點。
  • Flow Music：每月 10,000 點（約 2,000 首）、可同時生成 12 首、可商用。
  • Gemini app 裡的 Veo。
  • Google 相簿的照片轉影片與 Remix 有較高的每日上限。

怎麼開始

  • 用同一個帳號登入 Flow，先看點數餘額。
  • 點數參考：Veo 3.1-Lite 影片每次 10 點；放大到 1080p 對 Pro 免費；4K 放大 Pro 不能用。

要注意

  • 每天與每月的點數用不完都不會累積。
  • 點數用完可以買 AI credits，這要另外付錢。
  • 相簿功能只在選定國家、18 歲以上，官方頁沒有列出國家。Google TV Create Hub 只限美國。

來源：Flow 點數說明Google AI Pro 權益說明

Google AI Studio

AI Pro 給你什麼

  • AI Pro 權益說明沒有列出語音生成。
  • 可以用的是 Gemini API 的語音模型：gemini-3.8-flash-tts 與 gemini-3.8-flash-lite-tts，兩者都有免費層。

怎麼開始

  • 在 Google AI Studio 試模型、建立 API key，之後由程式或 AI 助理呼叫。

要注意

  • 這是另一本帳，付了 AI Pro 不代表 API 費用已包含。
  • 付費層到 2026-12-31 前，每 10 秒音訊約 US$0.00225（Flash）、US$0.0015（Flash-Lite），2027-01-01 起價格加倍。
  • 免費層的內容可能被用來改善 Google 產品，付費層不會。敏感內容別放免費層。
  • API key 不要貼給別人，也不要放在公開的地方。

Antigravity 桌面版、Jules 網頁

AI Pro 給你什麼

  • Antigravity：較高的 AI 代理使用上限，可優先試用實驗模型。
  • Jules：較高的任務數與同時執行數上限。
  • Google AI Studio：較高上限（Gemini 3.1 Pro 模型）。
  • Google Developer Program 進階權益：每月 US$10 Google Cloud 抵用額度等，不能與家人共用。

怎麼開始

  • Antigravity：下載桌面版（Windows、macOS、Linux）。
  • Jules：要先在 Jules 網頁連結 GitHub、選擇要開放的專案。
  • Developer Program：要把 AI Pro 連到你的 Google 開發者帳號，權益才會出現。

要注意

  • Antigravity 與 Jules 都要 18 歲以上，官方只正式支援英文。
  • Antigravity 用超過方案上限後，可能會用到需付費的 AI credits，先看設定。
  • 以 Google 帳號登入的 Gemini CLI，AI Pro 個人帳號已在 2026-06-18 停用，官方建議改用 Antigravity。
  • Jules 的 API 還是 alpha 測試版。

官方文件之間有出入

權益說明頁還列了 30 個 Firebase Studio 工作區與較高配額的 Gemini Code Assist。但開發者福利 FAQ 把工作區數量寫在舊版獨立方案下，而 Code Assist 的個人層已在 2026-06-18 停止服務。這兩項請以你帳號裡實際看到的為準。

搞懂哪些要另外付錢

AI Pro 的月費是入場券。下面幾種額度各算各的，不能互相抵用。

月費之外有六種額度各算各的；API 與 AI credits 會另外收費。

各服務的餘額頁

① 訂閱內含的使用上限

Gemini、Notebook、Antigravity、Jules 等「較高上限」，用到上限就要等下一輪。

② Colab 運算單位

AI Pro 含 200 個，只能用在 Colab。看餘額：Colab。

③ Flow 點數

每天 50 點加每月 1,000 點，只能用在 Flow，不累積。看餘額：Flow。

④ AI credits（要付錢）

方案內的點數或上限用完後，可以另外買來繼續用，例如 Flow、Antigravity。

⑤ Gemini API（另外計費）

給程式用的 API 有免費層；付費層要綁 Google Cloud 帳單，先預付至少 US$5，餘額 12 個月到期、不可退款。官方計費說明沒有提到 AI Pro 訂閱可以抵 API 費用。

⑥ Google Cloud 抵用額度

開發者權益的每月 US$10，抵用範圍依 Google Cloud 規則，和 API 預付餘額是兩筆不同的錢。

沒想清楚之前，先別開自動儲值、自動加購或超額扣款。
