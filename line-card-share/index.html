LINE 名片分享器

把一組 LINE 名片做成一條分享連結。放在你的官網上，訪客一按，LINE 就跳出選好友、選群組的畫面，對方收到的是可以左右滑的名片，不是一行網址。

為什麼需要它：LINE 的圖文名片（Flex Message）不能用貼網址的方式傳，網址貼進聊天室只會是一個連結。要讓一般人用自己的 LINE 把名片傳出去，得叫出 LINE 的分享畫面，這個小工具就是幫你叫出那個畫面。

已經有名片 JSON：做你自己的分享連結

  1. 先排好名片：到 LINE 官方的 Flex Message Simulator 排版，按右上角 View as JSON 複製。也可以請 AI 把你官網的自我介紹寫成 Flex Message JSON。
  2. 名片裡的圖片要放在 https:// 開頭的公開網址，最好就放在你自己的官網上。
  3. 貼到下面，按「檢查並預覽」。通過就會拿到分享連結和官網按鈕的程式碼。
  4. 用手機 LINE 打開分享連結，傳給自己或一個朋友試一次。

    幾件要知道的事

    名片存在連結裡。這個網站不保存你的名片內容，名片改了就重新產生一條連結，把官網按鈕換掉。

    第一次分享要按一次允許。第一次使用時 LINE 會跳出一次授權畫面，按允許之後才會出現選人畫面。

    只記分享次數。每送出一次記一筆次數，不記是誰、傳給誰。

    按鈕只能連到網址、LINE、電話、Email。其他類型的按鈕在這裡會被擋下來。

    連結走的是江江官網的分享頁。如果這顆按鈕對你的生意很重要，或是要交付給客戶，長期建議自己開一個 LINE 分享器，做法在教學文章第三段。

    最多 12 張。LINE 輪播一組最多 12 張；張數越多連結越長，建議 3 到 5 張。
