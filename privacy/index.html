這些工具是做什麼的

江江教練自己寫了一些小工具，幫自己整理社群上看到的好內容。例如讀取江江本人 YouTube 帳號按讚的影片、江江自己留下的留言，整理成筆記放進江江的個人知識庫。這些工具只給江江本人使用，不對外提供服務。

會讀取哪些資料

  • 只讀取江江本人授權的帳號資料，例如按讚的影片清單、影片標題與說明、江江自己的留言。
  • 不讀取、不收集其他使用者的個人資料。

資料怎麼使用與保存

  • 資料只用來替江江整理學習筆記。
  • 資料保存在江江自己的電腦與個人知識庫，不上傳到其他伺服器。
  • 不出售、不出租、不分享給任何第三方，也不用於廣告。

Google 使用者資料

本工具使用 Google API 取得的資料，遵守 Google API 服務使用者資料政策，包含其中的「有限使用」規定。

如何撤銷授權

授權可以隨時到 Google 帳戶的第三方存取設定移除。
