Skills 下載

把工作方法做成可以 clone 的 Claude Skills 技能包。Claude Code、Codex、Cowork、ChatGPT 都能讀。多為 MIT 授權，免費商用。

怎麼用？

按「複製連結」→ 貼給你的 Agent

叫它幫你說明這個技能包、做風險評估、檢查惡意指令、檢查跟使用者現有的系統、Skills 會不會衝突，如果都沒問題，並且使用者確認、同意後，協助下載安裝。
